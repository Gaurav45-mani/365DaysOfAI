📚 Topics Covered

1. The AI Ecosystem (AI vs. ML vs. DL vs. Data Science)
• Artificial Intelligence (AI): The broadest umbrella encompassing smart systems capable of performing tasks autonomously without continuous human intervention.
• Machine Learning (ML): A subset of AI focused on statistical methods and algorithms that learn patterns from data to analyze, visualize, predict, and forecast (e.g., Netflix and Amazon recommendation engines).
• Deep Learning (DL): A specialized branch of ML utilizing multi-layered artificial neural networks inspired by the human brain to handle complex unstructured data (e.g., object detection, computer vision, natural language processing).
• Data Science (DS): An interdisciplinary field combining AI, ML, statistics, and domain expertise to extract actionable insights from data across end-to-end analytical pipelines.

2. Paradigms of Machine Learning
• Supervised Learning:
  - Learns from labeled data where each training instance pairs input features with ground-truth output labels.
  - Solves Regression problems (continuous targets, such as house price prediction based on square footage) and Classification problems (discrete categories, such as spam detection).
• Unsupervised Learning:
  - Discovers latent structures, distributions, and hidden relationships within unlabeled data without explicit guidance.
  - Used for clustering, anomaly detection, and fraud pattern recognition.
• Reinforcement Learning (RL):
  - An autonomous agent learns optimal sequential decision-making strategies through continuous environmental interaction.
  - Maximizes cumulative reward signals via trial and error (e.g., autonomous driving, robotics, game-playing AI).
