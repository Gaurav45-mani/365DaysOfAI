## 🧠 Key Concepts

### Covariance
Covariance measures how two variables change together.

- Positive Covariance → Both variables move in the same direction.
- Negative Covariance → Variables move in opposite directions.
- Covariance does not have a fixed range, making interpretation difficult.

---

### Pearson Correlation
Pearson Correlation measures the strength of a **linear relationship** between two variables.

Range:
- **+1** → Perfect Positive Correlation
- **0** → No Linear Correlation
- **-1** → Perfect Negative Correlation

---

### Spearman Rank Correlation
Spearman Correlation measures the relationship using **ranked values** instead of actual values.

Useful when:
- Data contains outliers.
- Relationship is monotonic.
- Data is ordinal (ranked).

Range:
- **-1 to +1**
