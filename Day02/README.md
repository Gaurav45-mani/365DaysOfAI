## 🎯 Key Learnings

- Variance measures how far data points are spread from the mean.
- Standard Deviation is the square root of variance and is easier to interpret because it has the same unit as the data.
- Sample Variance uses **(n − 1)** instead of **n** to reduce estimation bias (Bessel's Correction).
- Histograms help visualize how numerical data is distributed across intervals.
- Skewness describes whether a dataset is symmetric or skewed to the left or right.
- Box Plots help identify the spread of data and detect potential outliers.
