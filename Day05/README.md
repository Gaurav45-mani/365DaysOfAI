## 🧠 Key Concepts

### Poisson Distribution

Poisson Distribution is a **discrete probability distribution** used to calculate the probability of a specific number of events occurring within a **fixed interval of time, distance, area, or volume**.

* λ (Lambda) → Average number of events
* Mean = **λ**
* Variance = **λ**
* Uses **PMF**

---

### Normal/Gaussian Distribution

Normal Distribution is a **continuous probability distribution** with a symmetric, **bell-shaped curve**.

* Mean = Median = Mode
* Mean (μ) → Determines the center
* Standard Deviation (σ) → Determines the spread
* Uses **PDF**

---

### 68–95–99.7 Rule

For a normal distribution:

* **68%** → Within ±1σ
* **95%** → Within ±2σ
* **99.7%** → Within ±3σ
